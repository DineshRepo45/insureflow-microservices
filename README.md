# insureflow-microservices
Microservice based Insurance Management System Using Java17,Spring Boot,Angular,Kafka and Docker


Backend:
- Java17
- Spring Boot
- Spring Cloud
- Kafka
- MySQL

Frontend:
-Angular

Infrastructure:
- Dcoker
- API Gateway
- Eureka Discovery

Services:

- Auth Service
- User Service
- Policy Service
- Claim Service
- Payment Service
- Notification Service
